## 📋 Descripción General

**Weekly Report CFC Importer** es una solución de escritorio desarrollada con una interfaz tipo *Consola de Control CCTV* para automatizar la extracción, validación, mapeo y consolidación de los reportes operacionales semanales de las plantas gestionadas para **Carbon Free Chile (CFC)** por **NovaSource Power Services**.

El sistema procesa archivos semanales recibidos en formato Excel (`.xlsx` / `.xlsm`), analiza los registros para evitar la duplicidad de datos, actualiza la información existente e integra automáticamente las nuevas entradas dentro del **Excel Maestro** centralizado, manteniendo un registro de auditoría en tiempo real.

---

## 🎛️ Características Principales

* **Procesamiento Automatizado:** Extrae, mapea y consolida datos entre reportes semanales de Excel y la base maestra.
* **Métricas en Tiempo Real:** Visualización instantánea de registros totales, insertados/actualizados y omitidos.
* **Consola de Logs:** Consola integrada para monitorear el progreso del flujo de trabajo y detectar errores de ejecución en vivo.


---

## 🛠️ Requisitos del Sistema

* **Sistema Operativo:** Windows 10 / 11 (64-bits) o macOS Big Sur / Sonoma / Sequoia (Intel y Apple Silicon).
* **Software Adicional:** Microsoft Excel o suite compatible para la lectura de planillas.
* **Conexión a Red:** No requerida (opera de forma 100% local en el equipo).
* **Entorno de desarrollo (opcional):** Python 3.10 o superior (Probado en Python 3.13).
